# arch-critical.md — Always-On System-Shape Facts (HOT tier)

## Critical facts (consult before deciding)
- **Phase 1 question**: can models recognize, retrieve, and generate sacred text, and reject false premises/incorrect texts? Interpretation/recommendation is Phase 2 — out of scope. Contract: Spec 1. **The question set is original-language editions only by default** (Spec 26): a text is in the pool iff `language == canonical_language`; four templates (retrieve_quote / complete_unit / cite_passage / verify_source), 28 questions/text.
- The **interchange format** is the working group's flat JSON (`{source:{tradition[],work,version,language,document_type,source_url?}, entries:[{unit_type,citation,text}]}`) — our internal representations must export to it losslessly. `tradition` is a LIST (traditions share texts).
- **Multi-faith by construction**: corpora are drop-in data (one converter registry line + a data directory per source); adding a tradition never changes core pipeline code.
- Pipeline shape is **four subsystems** (collection, scoring, analysis, visualisation) with **JSONL seams**: questions.jsonl → answers.jsonl → scores.jsonl. Stages are resumable; failed cells stay pending and exit non-zero.
- **Scoring = named graders + an always-on outcome (Spec 15).** Text-retrieval reports exact/normalized/token_f1/contains_reference; headline `correct` = OR of the SELECTED graders' verdicts (default `strict`+`containment` ⇒ `normalized OR contains_reference`), chosen via `score --evaluator` (a paid/separate-pass grader is expressible, never default — issue #21; `graders.py`). **Refusal is an OUTCOME, not a grader**: a declined cell is `refused`, excluded from `accuracy = correct/(correct+incorrect)`, with `coverage = (correct+incorrect)/n` reported beside every accuracy. Per-task rules + `_with_outcome` live in `score.py`. `normalize()` is script-aware (deletes Arabic/Hebrew marks + tatweel, folds alef-wasla/maqaf; KEEPS Devanagari/Gurmukhi vowel signs as part of the word and folds their digits — Spec 37) BEFORE the punctuation pass; Latin byte-for-byte unchanged (pinned snapshot) — never reorder. A deliberate contract change is a **sanctioned, oracle-witnessed rebaseline** (`test_contains_reference_rebaseline.py`), not a forbidden re-score. **verify_source is hardened (Spec 26, #23 PAPER GATE closed)**: `parse_yes_no` takes the **leading-stance** verdict (Yes/No must be the leading token of the first-sentence/60-char window, after stripping a bare `Answer:`/`Verdict:`/`Response:` label), read from the raw answer before `normalize()`; refused ⟺ no leading verdict (`parsed is None`), so a negation-evasion ("there is no way to verify this … yes") is refused, never scored correct.
- **Tool-use is part of panel identity**: a model's `tools` (e.g. Anthropic server-side `web_search`) is baked into `_panel_fingerprint` AND emitted as a real `panel.tools` list (the `model` is the raw API id, with no inline marker); the viewer's standings key is `provider\u0000model\u0000sortedTools` (missing ⇒ `[]`), so search on/off stay distinct rows while same-model/same-tools runs dedupe. `config.py` fail-fasts a tool on a non-anthropic provider; such runs are UNPRICED.
- **Copyright gate**: public-domain/open raw sources ARE committed under `texts/raw/` (with their `source.yaml`); only the `restricted` payloads (NABRE, Greek Orthodox TLG) and all of `texts/standardized/` are gitignored and rebuilt locally. Corpora derived from restricted translations are never committed.
- `pipelines/` is a single uv project (`sacredbench`); run via `uv --project pipelines run python -m sacredbench …` from the repo root. Providers: anthropic / any OpenAI-compatible host (base_url+api_key_env) / gemini; keys from env only.
- `apps/viewer/` is the **benchmark viewer over local `runs/`** (leaderboard + error explorer + cross-run standings; no GitHub data layer — the multibrowser surface it was seeded from is removed). Routes: `/`, `/run/$runId/model/$modelId`, `/standings`; read `apps/viewer/README.md` before touching it.
- **Copyright audit gate** (`pipelines/sacredbench/audit.py`, in `.codev/checks/test.sh`): no committed artifact may derive from a `restricted` source — origin always, plus a restricted-text content layer when the held-back payloads are present locally. Never commit a standardized doc or run artifact built from a restricted target.
